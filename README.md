## Proyectos

**[Conta Ayuda API](https://github.com/Laura-Montana/Conta_ayuda)**
Muchas empresas no cuentan con herramientas accesibles para analizar sus datos financieros. Esta API recibe archivos CSV o JSON, valida los datos y devuelve métricas, tendencias, comparación entre períodos y detección de anomalías.
`FastAPI` `Pandas` `Scikit-learn` `Pytest` `GitHub Actions`

**[Control Financiero Automatizado](https://github.com/Laura-Montana/gastos-automatizados)**
Pipeline que lee las notificaciones de mis bancos por correo, las categoriza y las muestra en un dashboard. Se ejecuta solo, todos los días.
`Python` `Gmail API` `Supabase` `Streamlit` `GitHub Actions`
